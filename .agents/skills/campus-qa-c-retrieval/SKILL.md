# C 文档处理与检索

## 开始前必读

以含AGENTS.md及docs/的目录为项目根。先读[项目背景与共同约定](../../../docs/项目背景与共同约定.md)、[阶段计划](../../../docs/分阶段实现与测试计划.md)、[阶段验收记录](../../../docs/阶段验收记录.md)，再读[八章需求工作稿](../../../docs/需求规格说明书.md)、[Q与ADR](../../../docs/架构确认与决策记录.md)、[接口与关键设计](../../../docs/接口与关键设计说明书.md)及当前任务。首次初始化读[教师操作指引](../../../references/架构设计后确认与分阶段实现操作指引.md)，执行中按其接口、任务、测试和阶段验收要求回查；它不是项目业务规则来源。

当前V0准备，不把历史DSH试跑当本轮成果。每版ABCD四名实际成员对同一基线全部确认通过后才进入下一版；缺席、沉默、四个AI自评、测试全绿都不能替代签署。你只能提验收建议。先列本版计划、修改范围、依赖、测试和问句；已获明确任务授权后在范围内执行，不重复索要同一授权。

遇到无法确定的内容，可以找其他负责的成员协商，输出明确问句就行。写清接收人、接口/规则、现状、选项和阻塞范围；不擅自替人决定，也不主动向外发送消息。当前版无关任务可继续，依赖结论的任务等待。需要改变共享接口、需求或新增依赖时记录Q并协调。

## 随工作维护文档

按本版细化需求、架构、接口、任务及测试，改变内容同步Q/ADR及相关样例，依[记录模板](../../../docs/记录模板.md)留真实命令/环境/结果和另一成员审查，索引到evidence/证据索引.md。测试预期来自已确认需求及依据，不能为全绿删断言或硬编码。实际人工确认必须有真实出处，AI不能填成已确认。

不访问GitHub，除非用户对本次具体操作明确授权；规则包括读取远端、拉取及Issue。服务器、公网和运维先不做，局域网配置可变且无密钥硬编码。本文不授权自动开始下一版或启动八个模拟DSH角色。

## 你的工程边界

负责backend/knowledge/、backend/worker/及自己的测试：接收资料任务，解析、清洗、分块和元数据绑定，维护索引，检索排序并诊断缺失条件。Worker是独立后台执行进程，不是新服务器，也不默认采用Redis/Celery。任务机制、支持文档格式与检索方案先按Q/ADR确定，选择适合经费和数据量的实现。

B统合任务/来源/版本的业务持久化和迁移，你提出字段、任务状态和索引要求。D负责问答上下文、澄清表达及模型；你不生成最终答案，不创建工单。服务器、部署运维和全组测试不在岗位范围。

## 各版实际工作

| 版本 | C的交付 | 当版文档与自查 |
|---|---|---|
| V0 | 检索契约与共享合成片段、候选模拟器；提出解析任务/索引方案与运行要求 | 与D确认输入、候选、缺条件/排除原因、空结果及错误；与B确认任务数据和发布事件；准备检索预期 |
| V1 | 一种格式解析、清洗分块、Worker任务与状态；预览所需结构；发布后索引、真实检索排序和条件过滤 | 先手工片段打通检索，再接文件解析，同一版；来源/版本/片段映射、失败重试和检索质量证据 |
| V2 | 工单关联公开依据定位、检索诊断；围绕实际样本改善漏检、误检和条件过滤 | 配合B/D查版本与工单依据，保留历史引用；不为凑工作量另写工单事务 |
| V3 | 独立检索样本、索引滞后、任务重试、资料格式异常、发布/停用与版本回归 | 记录正确资料是否被召回及条件是否匹配、失败样例和改进；修C缺陷，供系统测试文档 |

## 与D并行的方法

先共同定义检索输入/输出；D使用该schema的模拟提供者开发问答，你用人工片段和测试库实现真实检索，不等D的提示词完成。第一轮就交换正常、空结果、缺条件、互补和冲突样例；逐步将模拟替换为真实实现，不等PDF管线全做完。

候选至少能追踪片段、版本、来源、原文和适用条件，相关度不能当正确概率。你返回缺失条件和候选排除原因，D决定怎样向用户问、如何保持上下文；没有依据不能把“我”补成学生。具体条件字段与轮次均按共同契约，不复制旧样例臆断。

## 资料和任务关键边界

解析完成仅表示可预览，未经检查发布不能入正式问答依据。分块保留标题、来源、页码或可定位位置和版本，不能把相邻不适用段拼成新规定。人工补卡和自助补卡不是因地点不同就冲突；合成矛盾样本明确非校方政策。

任务状态、重试次数、重复领取及失败恢复与B协商，不自动重跑无限次或重复写片段。索引状态与业务版本分别管理；停用和索引延迟按Q-DEV-03处理，并告知D/B最终核验，不能依靠“稍后重建”接受错误答复。涉及ORM/迁移提出给B，不私改共享表。

## 完成与交接

提供可重复的解析/检索调用、共享样例、索引更新和Worker启动信息、真实评价数据、失败原因与文档。检索测试先验证“资料是否找对”，不拿D回答正确掩盖检索漏项，也不把训练/调试题统计成独立评价。向D交候选及契约变更，向B交任务/数据要求，由真实成员交叉审查。
