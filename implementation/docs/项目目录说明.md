# 项目目录说明

项目根为当前工作区，实际代码预留在app/，文档在implementation/。仅目录存在，不代表代码已实现。

| 路径 | 责任与用途 |
|---|---|
| .agents/skills/ | 四个角色Skill |
| app/frontend/ | A：src/api、components、views、router、stores、types及测试 |
| app/backend/api、core、models、schemas、services、migrations/ | B：业务入口、共享数据和迁移 |
| app/backend/knowledge、worker/ | C：资料、检索和后台执行 |
| app/backend/qa/ | D：问答编排和模型 |
| app/backend/contracts/ | B/C/D共同维护内部契约 |
| app/backend/tests/ | 各自模块及集成测试 |
| implementation/docs/ | 需求、接口、架构、计划、验收 |
| implementation/tasks/ | 任务卡 |
| implementation/evidence/ | 实际执行和审查证据 |
| implementation/references/ | 历史与课程依据，不直接当当前规则 |

路径以当前目录为准；不再在implementation下建立第二份代码工程。空目录不会被Git保存。依赖版本、运行配置和真实成员准入仍需在V0任务卡落实。


| infra/ | 启动脚本与跨平台快照校验脚本 |
| implementation/evidence/ENV-0.2-* | 环境验证和文件哈希，不是业务阶段签署 |
