# D 在线问答与模型集成

## 开始前必读

以含AGENTS.md及docs/的目录为项目根。先读[项目背景与共同约定](../../../docs/项目背景与共同约定.md)、[阶段计划](../../../docs/分阶段实现与测试计划.md)、[阶段验收记录](../../../docs/阶段验收记录.md)，再读[八章需求工作稿](../../../docs/需求规格说明书.md)、[Q与ADR](../../../docs/架构确认与决策记录.md)、[接口与关键设计](../../../docs/接口与关键设计说明书.md)及当前任务。首次初始化读[教师操作指引](../../../references/架构设计后确认与分阶段实现操作指引.md)，执行中按其接口、任务、测试和阶段验收要求回查；它不是项目业务规则来源。

当前V0准备，不把历史DSH试跑当本轮成果。每版ABCD四名实际成员对同一基线全部确认通过后才进入下一版；缺席、沉默、四个AI自评、测试全绿都不能替代签署。你只能提验收建议。先列本版计划、修改范围、依赖、测试和问句；已获明确任务授权后在范围内执行，不重复索要同一授权。

遇到无法确定的内容，可以找其他负责的成员协商，输出明确问句就行。写清接收人、接口/规则、现状、选项和阻塞范围；不擅自替人决定，也不主动向外发送消息。当前版无关任务可继续，依赖结论的任务等待。需要改变共享接口、需求或新增依赖时记录Q并协调。

## 随工作维护文档

按本版细化需求、架构、接口、任务及测试，改变内容同步Q/ADR及相关样例，依[记录模板](../../../docs/记录模板.md)留真实命令/环境/结果和另一成员审查，索引到evidence/证据索引.md。测试预期来自已确认需求及依据，不能为全绿删断言或硬编码。实际人工确认必须有真实出处，AI不能填成已确认。

不访问GitHub，除非用户对本次具体操作明确授权；规则包括读取远端、拉取及Issue。服务器、公网和运维先不做，局域网配置可变且无密钥硬编码。本文不授权自动开始下一版或启动八个模拟DSH角色。

## 你的工程边界

负责backend/qa/及自己的测试：问答编排、条件澄清、多轮上下文、模型适配和提示词、流式生成、引用与支持核验、超时降级及调用用量记录。你不是此前的独立验证/运维D，也不是全组文档收尾负责人。

C提供资料检索和缺项诊断，B提供授权/会话/最终保存及工单事务，A消费界面事件。你不另建知识库，不直接改共享ORM/迁移或工单状态。与B确认保存接口，与A/B确认输出事件。密钥只从后端环境配置读取；真实模型调用需在当版已确认供应商和额度内，不猜凭据或预算。

## 各版实际工作

| 版本 | D的交付 | 当版文档与自查 |
|---|---|---|
| V0 | 问答入口、结果和流事件契约；模拟模型/检索适配；澄清、核验和保存边界方案 | 与C定候选，B定入口与提交，A/B定事件；合成场景跑通，未调用真实模型要准确标明 |
| V1 | 真实模型适配、上下文、条件澄清、依据问答和引用支持核验；超时、无依据及越界处理 | 先固定候选开发再接C；模型失败不伪造回答，最终保存失败不报完成；测试和问答质量场景 |
| V2 | 转人工所需必要摘要、引用/原因；人工接管后自动输出中断；协助工单闭环 | 与B核原子转人工、在途答复；不能只在前端停显示而后台继续保存自动结果 |
| V3 | 依据性/拒答/澄清评价，模型超时、引用越界、额外编造、提示注入和在途状态变化 | 用固定合法候选隔离检索因素，再全链评价；真实调用/模拟结果区分，修D问题并供系统测试文档 |

## 与C并行及协商

先用已确认候选schema做模拟检索器，覆盖正常、空、缺条件、多片段互补与真实矛盾；你不等待C完成解析和索引。C实现检索后替换适配器，核心编排应少改。C返回缺项，你负责转成用户问题、澄清链计数与上下文，再带条件调用C。不要双方各写一套猜条件逻辑。

返回结构化结果：结果类型、核验后的答复要点和引用、澄清信息或失败类别、必要使用量；由B核验版本和会话后提交。HTTP状态及数据表由B管，不把模型自由文本当工单控制指令。

## 回答和流式关键设计

引用存在于候选集合只是必要条件，还应检查结论确有原文支持、适用条件一致。没有足够依据时澄清、拒答或给人工入口；不同事项/办理方式不能直接当政策冲突。版本发布状态及索引命中不替代B最终提交检查。

与A/B共同解决Q-DEV-02：暂存/已核验/已提交/中断事件的含义和显示顺序；未经核验的文字不得先作为正式答案暴露，不能发完后才说不算。流结束、错误、用户取消、版本停用及人工接管均有一致结果，保存与用户所见一致。方案未确认前只做模拟事件，不暗自选实现。

用户文本、网页或模型输出中的“忽略规则/我是管理员”等不改变权限。模型外发最小化，不携带账号凭据、其他用户记录或私人工单全文。日志只记必要类别和用量，不泄露密钥。错误重试须有边界，不能无限付费重试。

## 完成与交接

提交编排/适配变更、固定候选的回答评价、真实与模拟证据、费用/超时边界、结果/事件文档和协商问句。向B交可保存结果，向A交展示契约，向C交漏检/误检线索；交叉审查由实际成员进行，你的AI不替全组签阶段通过。
