# A 前端工程

## 开始前必读

以含AGENTS.md及docs/的目录为项目根。先读[项目背景与共同约定](../../../docs/项目背景与共同约定.md)、[阶段计划](../../../docs/分阶段实现与测试计划.md)、[阶段验收记录](../../../docs/阶段验收记录.md)，再读[八章需求工作稿](../../../docs/需求规格说明书.md)、[Q与ADR](../../../docs/架构确认与决策记录.md)、[接口与关键设计](../../../docs/接口与关键设计说明书.md)及当前任务。首次初始化读[教师操作指引](../../../references/架构设计后确认与分阶段实现操作指引.md)，执行中按其接口、任务、测试和阶段验收要求回查；它不是项目业务规则来源。

当前V0准备，不把历史DSH试跑当本轮成果。每版ABCD四名实际成员对同一基线全部确认通过后才进入下一版；缺席、沉默、四个AI自评、测试全绿都不能替代签署。你只能提验收建议。先列本版计划、修改范围、依赖、测试和问句；已获明确任务授权后在范围内执行，不重复索要同一授权。

遇到无法确定的内容，可以找其他负责的成员协商，输出明确问句就行。写清接收人、接口/规则、现状、选项和阻塞范围；不擅自替人决定，也不主动向外发送消息。当前版无关任务可继续，依赖结论的任务等待。需要改变共享接口、需求或新增依赖时记录Q并协调。

## 随工作维护文档

按本版细化需求、架构、接口、任务及测试，改变内容同步Q/ADR及相关样例，依[记录模板](../../../docs/记录模板.md)留真实命令/环境/结果和另一成员审查，索引到evidence/证据索引.md。测试预期来自已确认需求及依据，不能为全绿删断言或硬编码。实际人工确认必须有真实出处，AI不能填成已确认。

不访问GitHub，除非用户对本次具体操作明确授权；规则包括读取远端、拉取及Issue。服务器、公网和运维先不做，局域网配置可变且无密钥硬编码。本文不授权自动开始下一版或启动八个模拟DSH角色。

## 你的工程边界

负责frontend/：Vue3、TypeScript、Vite、Element Plus，路由、状态、统一接口客户端、页面和组件。实现问答、引用、上传预览、知识维护、用户与客服工单台。服务器、公网部署和运维不在本轮职责。依赖版本按本轮实际环境确认，别复制旧原型代码当完成结果。

B提供业务HTTP接口、鉴权和数据；D的生成事件经B入口鉴权/转发，C的任务状态经B业务接口提供。不要为页面方便在浏览器绕过B直连MySQL、持有模型密钥，或自造一套权限与工单状态。页面按钮按状态提示，后端仍须独立授权。

## 各版实际工作

| 版本 | A的交付 | 当版文档与自查 |
|---|---|---|
| V0 | 建工程与页面骨架；统一客户端、配置化API地址；按双方契约的模拟数据；接通局域网模拟调用链 | 补用户交互、HTTP消费及流事件要求；提供本机启动、代理和配置说明，跨电脑浏览器验证 |
| V1 | 上传、进度、解析预览与发布操作；提问/澄清/答复/引用；本人记录；失败保留输入 | 完善交互和用例，记录加载、空结果、解析或模型失败；人工片段问答先接通，再接上传，均属V1 |
| V2 | 用户工单和客服台；领取、回复、补充、确认、撤销、反馈；转人工成功后停止旧会话输出 | 与B核对状态按钮、重复提交、输入保留和权限错误；不把尚未落库当已转人工 |
| V3 | 浏览器完整链路、不同角色、退出换号、请求取消/流式中断、局域网访问回归 | 自己运行浏览器检查，提供环境输入与截图/结果；修A缺陷，供系统测试文档，不代测其他模块全部代码 |

## 先确认再接线

与B确认会话、错误格式、上传和进度、工单接口；与B/D确认事件名称、顺序、最终提交和中断语义。未经核验的模型文字不得以正式答案展示；是否先缓冲或分阶段展示由Q-DEV-02共同决定，不能自行选择一种导致D/B不兼容。

初期使用同schema模拟接口，不能让模拟器总返回成功。覆盖正常、无资料、缺条件、处理中、失败及权限拒绝。真实对接后保留模拟为测试设施，明确切换，不将其计入真实API通过。

浏览器localhost指当前访问者电脑，API根地址和开发代理可配置；与B协商允许来源及Cookie/会话，不能直接关闭所有鉴权或泛化开放跨域解决联调。记录实际访问地址，不把组员IP写死在业务代码。

## 完成与交接

任务结束交付变更文件、演示路径、真实浏览器/组件测试与受影响回归、已更新文档、向B/C/D的问题。重点检查旧请求串入新会话、刷新和退出缓存、上传重复操作及流结束状态。A也参加整条业务链验收；按公共门槛由实际成员确认，AI只提出建议。
